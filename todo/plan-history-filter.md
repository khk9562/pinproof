# 보관함 · 이전 기록: 발견일 · 넘김일 표시, 교집합 필터, 날짜 묶음

## 목표

보관함이 쌓여도 이력을 찾을 수 있게 한다.

- 항목마다 **발견일**(담은 시각, frontmatter `created`)과 **넘김일**(프롬프트로 넘긴 시각, `sent`)을 따로 보여 준다. 둘 다 이미 저장되므로 새로 기록할 것은 없다
- 보관함은 **카테고리 × 기간**을 함께 거르고(교집합), 남은 항목을 **날짜별로 묶어** 보여 준다
- 이전 기록은 카테고리 · 넘김일이 없어 **만든 날짜 기준 기간 필터 + 날짜 묶음**만

## 결정 (사용자, 2026-10-26)

- 기간: 프리셋(전체 · 오늘 · 최근 7일 · 최근 30일)
- 카테고리: 하나만 고름(전체 + 보관함에 실제로 있는 카테고리)
- 기준 날짜: 넘김일 / 발견일 중 고름. 기간 필터와 날짜 묶음이 같은 기준을 쓴다. 넘김일 기준이면 넘기지 않은 항목은 맨 아래 "넘기지 않음" 묶음(기간을 고르면 빠짐)
- 묶어 보기(전환 아님), 처리 완료 날짜는 기록하지 않음
- 필터 글자는 작게(`--text-label`) — 자리를 덜 차지하게
- 이전 기록에도 적용

## 할 일

- [x] 항목 줄을 펼치면 `발견 10/24 14:05 · 넘김 10/25 09:12` (대기 · 다른 주소 · 보관함 모두. 넘기지 않았으면 "넘기기 전")
- [x] 보관함: 필터 줄(카테고리 · 기준 · 기간) + 날짜 묶음 제목(`10월 26일 2`), 결과가 없으면 걸린 조건과 [조건 지우기]
- [x] 이전 기록: 기간 필터 + 만든 날짜 묶음(날짜가 없는 옛 기록은 "날짜 없음")
- [x] 필터 상태는 패널이 열려 있는 동안 유지(구역을 접었다 펴도 그대로)
- [x] e2e: 펼친 줄의 날짜, 카테고리 × 기간 교집합, 결과 없음 → 조건 지우기, 이전 기록 기간 필터
- [x] 타입 · 단위 · e2e · 빌드, 라이트 · 다크 화면 확인

## 주의

- 보관함 비우기 · 이전 기록 모두 삭제는 필터와 무관하게 **전부** 지운다(버튼 이름 그대로)
- 날짜 문자열은 `YYYY-MM-DDTHH:MM`(nowStamp). 옛 기록은 `created`가 없을 수 있다
- 연도가 올해가 아니면 묶음 제목 · 날짜에 연도를 붙인다
- 이전 기록 정렬: 예전엔 전체를 "보관 안 된 것 먼저 → 번호 내림차순", 이제 날짜 묶음 안에서만 그 순서(최근 날짜 묶음이 위)
