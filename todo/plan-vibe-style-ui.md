# Vibe Annotations 스타일 UI 재설계 계획

> 2026-10-19 · 브랜치 `feat/vibe-style-ui`
> 근거: Vibe Annotations 소스(`raphaelregnier/vibe-annotations`, PolyForm Shield) UX 분석. **코드는 옮기지 않고 동작·배치만 참고**한다.

## 목표

사용자가 Vibe Annotations와 비슷한 사용 경험을 갖게 한다. 페이지 위에서 고르고, 그 자리에서 메모하고, 마커로 확인하는 흐름이다.
색은 **화이트 바탕 + 그린(주 버튼·선택) + 연두(마커·하이라이트)** 로 한정한다. 빨강·주황은 오류·경고 상태에만 쓴다.

완료 기준
- 사이드 패널을 열면 그 탭 오른쪽 위에 플로팅 툴바가 뜨고, 패널을 닫으면 사라진다
- 요소·텍스트·영역을 고르면 그 자리에 팝오버가 뜬다. Enter=담기, Esc=취소. 담은 뒤에도 같은 모드가 계속된다
- 담은 증거는 그 요소 위에 A·B·C 연두 마커로 보인다(미분류는 문자 없는 회색 점). hover=메모 툴팁, 클릭=편집 팝오버
- 패널의 증거는 한 줄 목록이다. 누르면 펼쳐지고, 같은 페이지면 그 요소로 스크롤해 마커가 반짝인다
- 기존 기능(소스 위치, 스크린샷, 네트워크, 붙여넣기, 보관·삭제, md 형식)은 그대로 동작한다. md 출력 형식은 바꾸지 않는다

## 구조

```
사이드 패널 (usePinProof)                       content script (picker.content)
  상태의 주인: 작성 중 기록, 미분류, 파일 저장       화면의 주인: 툴바 · 팝오버 · 마커 · 선택 도구
          │  chrome.tabs.connect(tabId) 포트  ─────────────►  onConnect: 툴바 표시
          │  bn:state {draft, inbox, record 칩}  ────────►    마커 다시 그리기 · 툴바 칩 갱신
          │  ◄──────── bn:captured {evidence + memo}          팝오버에서 Enter
          │  ◄──────── bn:evidence-edit {uid, memo|delete|move} 마커 편집 팝오버
          │  포트 끊김(패널 닫힘·탭 이동) ────────────►    툴바·마커 숨김, 모드 종료
```

- 지금 쓰는 `chrome.runtime.sendMessage`(`bn:captured`·`bn:mode`·`bn:hello`)와 `chrome.tabs.sendMessage`(`bn:start` 등)는 유지하고, 패널 존재 감지와 상태 전달만 포트로 더함. 포트는 끊기면 바로 알 수 있어 "패널이 열려 있을 때만" 조건을 지키기 쉬움
- 툴바 위치는 content script가 `chrome.storage.local`(`toolbarPos:<origin>`)에 저장

- **md 출력 형식 불변**: WORKFLOW·Claude 처리가 기대는 형식이라 `lib/markdown.ts` 출력은 바꾸지 않음(증거 문자·한 줄 메모 위치 그대로)
- **스크린샷 타이밍**: 팝오버·마커·툴바가 찍히지 않게, 클릭 순간(팝오버 열기 전)에 오버레이를 숨기고 캡처. 영역 모드도 같음
- **호스트 앱 간섭**: 툴바·팝오버는 Shadow DOM 안, 페이지 스타일과 단축키에 영향 없게. 팝오버 입력 중에는 Alt+Shift 단축키·화살표 이동을 무시(현재 `isTyping`이 shadow 안 입력을 잡는지 확인)
- **z-index**: host 2147483647 유지. 앱의 모달 위에도 떠야 함
- **연두 대비**: 연두(#a3e635 근처) 위 흰 글자는 대비 부족 → 마커 글자는 짙은 녹색. 흰 바탕 위 연두 테두리도 약함 → hover 하이라이트 테두리는 그린, 채움만 연두
- **여러 탭**: 같은 앱을 두 탭에서 열면 패널이 붙은 탭에만 툴바
- **스크린샷 강조색**: `screenshot()`이 잘라낸 이미지에 파란 테두리(#2563eb, `index.ts:477`)를 그림 → 그린으로 바꾸면 이후 md 첨부 이미지 색이 달라짐(의도된 변경)
- **패널 없이 단축키**: 툴바는 패널이 있을 때만 뜨지만 `Alt+Shift+E/T/R/N`은 페이지 키 리스너라 패널 없이도 눌림 → 지금의 "사이드 패널을 먼저 열어주세요" 경고(`index.ts:496`) 유지
- **훅·게이트**: 이 저장소엔 `.claude/`·git 훅·CI가 없음. 게이트는 `npm test`·`compile`·`build`·E2E뿐
- **E2E 브라우저**: 이 맥에는 Playwright Chromium 1248이 없어 1200을 `PLAYWRIGHT_BROWSERS_PATH`로 가리켜 실행 중(별도 설치 필요)
